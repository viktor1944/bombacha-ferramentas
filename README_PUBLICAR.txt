QUICKDROP — RELEASE NECESSÁRIA
Crie uma nova Release no GitHub usando EXATAMENTE:
Tag: quickdrop-v2.0.1
Título: QuickDrop v2.0.1 CLEAN
Arquivo: QuickDrop_v2.0.1_Portable.zip

IMPORTANTE: NÃO marque a Release do QuickDrop como Latest, porque atualmente o botão automático do Bombacha WhatsApp usa /releases/latest/.

COMO PUBLICAR O SITE
1. Extraia o ZIP do site.
2. Abra bombacha-ferramentas-main.
3. Envie TODO o conteúdo dessa pasta para a raiz do repositório.
4. Faça Commit changes.
5. Aguarde o GitHub Pages atualizar e teste em janela privativa.
