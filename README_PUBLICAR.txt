BOMBACHA FERRAMENTAS — SITE OFICIAL

CONTEÚDO
- Site responsivo em HTML, CSS e JavaScript puro.
- Página inicial, catálogo, recursos, histórico, FAQ, sobre, termos e privacidade.
- Primeiro programa: Recorta Fácil v1.0.4 Offline.

ANTES DE PUBLICAR
1. Crie um repositório no GitHub chamado bombacha-ferramentas.
2. Crie uma Release e envie o arquivo:
   Bombacha_Ferramentas_Recorta_Facil_Setup_v1.0.4_Offline.exe
3. Abra o arquivo config.js deste site.
4. Troque SEU-USUARIO pelo nome do seu usuário do GitHub.
5. Publique esta pasta no Netlify, Cloudflare Pages ou GitHub Pages.

CONFIGURAÇÕES CENTRALIZADAS
Edite somente config.js para atualizar:
- URL do instalador
- versão
- tamanho
- SHA-256
- data de atualização

TESTE LOCAL
Dê dois cliques em index.html. Para testar recursos de navegador com mais fidelidade, execute:
python -m http.server 8080
e abra http://localhost:8080

PUBLICAÇÃO RÁPIDA NO NETLIFY
- Entre no Netlify.
- Escolha Add new project > Deploy manually.
- Arraste esta pasta ou o ZIP do site.

OBSERVAÇÃO SOBRE O INSTALADOR
O EXE não foi incluído dentro deste ZIP do site. A forma recomendada é colocá-lo em uma GitHub Release e usar o link no config.js.
