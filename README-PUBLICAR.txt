BOMBACHA PELOTAS — PÁGINA MULTILÍNGUE + CLOUDFLARE + TELEGRAM

1. Extraia este pacote TAR.GZ ou ZIP no seu computador.
2. Acesse https://github.com/viktor1944/bombacha-ferramentas
3. Na raiz do repositório, use Add file > Upload files.
4. Envie os arquivos bombacha-pelotas.html e bombacha-pelotas-vpn.html.
5. Envie também pelotas-favoritos.json se quiser garantir a lista oficial dos dez sites.
6. Confirme em Commit changes (branch main).
7. Teste https://viktor1944.github.io/bombacha-ferramentas/bombacha-pelotas.html

NOVIDADES:
- Seletor no topo: Português, English, Español, Français, 中文, हिन्दी, العربية e Русский.
- Tradução incorporada no HTML da HOME, sem serviços externos.
- Idioma salvo por visitante neste navegador.
- Aviso claro de que o Bombacha Pelotas é configurado com Cloudflare DNS.
- Recomendação de VPN se o site continuar sem abrir.
- Link para o grupo Telegram na barra, na home e na divulgação.
- Guia VPN atualizado com explicação do DNS Cloudflare.
- Os dez favoritos, o ranking arrastável e a sincronização foram preservados.

IMPORTANTE:
A seleção de idiomas traduz a HOME (não traduz sites externos nem o guia VPN).
DNS sobre HTTPS não é VPN. A página pública não muda o DNS de outros navegadores.
Não é preciso reinstalar o navegador para atualizar esses HTML no GitHub.
