⚽ Futebol ao vivo num só lugar

O Bombacha Pelotas reúne dez sites indicados pelo projeto em uma página inicial esportiva. Os cartões podem ser arrastados para você montar sua própria ordem de preferência, salva no navegador.

Quer experimentar sem instalar? Abra a página inicial do Bombacha Pelotas. Para ter a configuração pronta para uso, baixe o instalador do Windows.

☁️ Cloudflare 1.1.1.1 já configurado

O navegador Bombacha Pelotas para Windows vem com DNS sobre HTTPS (DoH) da Cloudflare 1.1.1.1 pré-configurado. Isso pode ajudar quando um endereço não abre por problemas ou restrições de DNS da operadora.

Está acessando por outro navegador? Alguns sites podem não abrir por causa do DNS utilizado. Caso continue com problemas de acesso, consulte nosso guia de VPN. O Cloudflare DNS não é uma VPN, não troca seu país e não garante acesso a todos os sites.

Duas formas de usar

  • Bombacha Pelotas para Windows: instale o navegador com Cloudflare DNS já configurado, tema escuro e acesso à home.
  • Em qualquer navegador: abra a página de favoritos diretamente no site, sem instalar nada.

Principais recursos

  • Dez sites de futebol em uma home esportiva.
  • Favoritos arrastáveis, com ordem pessoal salva neste navegador.
  • Links oficiais da lista atualizados pelo GitHub.
  • Seletor de oito idiomas na página inicial.
  • Faixa VPN nos sites sinalizados e guia para aprender a usar VPN.
  • Botão para participar do grupo do Telegram.

🔒 E se um site não abrir?

Se o Cloudflare DNS não resolver o problema, pode ser necessário experimentar uma VPN. Alguns sites, como PirloTV, FintTV, Rede Canais TV e LiveTV, têm uma faixa VPN na home. Leia as orientações antes de instalar.
